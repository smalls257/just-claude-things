# just-claude-things

Personal collection of Claude Code skills, prompts, and tools — built for daily use, available to share.

## Structure

```
skills/     # Claude Code / Superpowers skill files
prompts/    # Reusable prompt templates
tools/      # Scripts and utilities
```

## Usage

Skills drop into `~/.claude/plugins/` or any project's `.claude/` directory.

Prompts and tools are standalone — copy, adapt, use.
